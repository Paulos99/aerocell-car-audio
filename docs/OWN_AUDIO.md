# Свой трек с телефона

Посетитель нажимает на планшете «Свой трек», сканирует QR и загружает свой аудиофайл. Трек появляется в списке как «СВОЙ ТРЕК» и играет через тот же баланс: слева коробка AEROCELL, справа — без обработки.

## Как это устроено

Файл идёт через облако. Планшет создаёт одноразовую сессию в функции Yandex Cloud `aerocell-upload`. QR ведёт на страницу `https://storage.yandexcloud.net/aerocell-stand/u/index.html?t=<токен>`. Телефон открывает её через обычный мобильный интернет, получает одноразовую ссылку и отправляет файл (mp3, m4a, aac, wav, flac, ogg, до 50 МБ) прямо в бакет. Объект лежит в префиксе `uploads/` и снаружи не читается: планшет забирает его по временной ссылке, затем просит функцию удалить файл. То, что осталось, бакет сам стирает через сутки.

К Wi-Fi стенда подключаться не нужно. Планшету хватит любого интернета, в том числе гостевого с изоляцией клиентов.

Загруженный файл на планшете удаляется при перезапуске приложения, когда стенд уходит в режим простоя (через 2 минуты без касаний, если музыка не играет) и через 10 минут без касаний экрана, даже если трек всё ещё играет. В последнем случае музыка сначала плавно затихает, потом кнопка «Свой трек» возвращается к «Загрузить свой». Время задаётся в манифесте: `config.ownTrack.resetAfterMin` (по умолчанию 10).

Пока файл идёт с телефона, на планшете открыт экран загрузки: логотип, имя трека, четыре шага «Ждём файл», «Загружается», «Готовим», «Готово» и полоса прогресса. Телефон сообщает облаку настоящий процент отправки (`action=progress`), планшет видит его в ответе `status` и показывает на полосе. Если облако процент не прислало, по полосе бежит блик. Шаг «Готовим» — это скачивание файла на планшет, его процент считается на самом планшете. Потом галочка, плавный уход в чёрный и мягкое начало музыки.

Способ доставки вынесен за интерфейс `VisitorUploadTransport`. По умолчанию используется `CloudUploadTransport`. Локальный сервер `LocalHttpUploadTransport` оставлен запасным вариантом: если в `upload-cloud.properties` нет адреса функции, приложение поднимает страницу на самом планшете, как раньше.

## Настройка

Секреты бакета в приложение не попадают. В `upload-cloud.properties` (файл в корне проекта, в git не попадает) нужны только адрес функции и секрет стенда:

```
UPLOAD_FUNCTION_URL=https://functions.yandexcloud.net/<id>
UPLOAD_STAND_SECRET=...
UPLOAD_USE_CLOUD=true
```

Функцию и правило очистки префикса `uploads/` ставит скрипт `tools/deploy_upload_function.sh`.
