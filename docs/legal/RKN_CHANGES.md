## Что сейчас в продукте

Приложение не содержит форм ФИО, телефона, email, регистрации, cookie-баннера и своей аналитики. Загрузка своего аудиофайла не отправляет файл на сервер.

Технические журналы доступа может вести GitHub Pages (IP, User-Agent) по своей политике. Это обработка на стороне GitHub, не форма на сайте.

## Как подать (когда появится ИНН и решение юриста)

1. Открыть [реестр операторов](https://pd.rkn.gov.ru/operators-registry/operators-list/) и найти карточку по ИНН.
2. Если записи нет и юрист подтвердит, что вы оператор — подать **первичное** уведомление по ст. 22 152-ФЗ через [формы РКН](https://pd.rkn.gov.ru/) (приказ РКН от 28.10.2022 № 180).
3. Если запись уже есть — подать **уведомление об изменении**, а не новое первичное.
4. Не подавать уведомление «на всякий случай» без правовой квалификации: сейчас на сайте нет форм ПД.

Исполнитель уведомление не подаёт.
