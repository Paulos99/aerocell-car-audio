# Служебное меню стенда AEROCELL

Это инструкция для персонала, не для посетителя. В подсказке «?» на экране стенда этих пунктов нет.

## Как открыть

На экране сравнения зажмите логотип AEROCELL вверху и держите, пока не откроется окно «Служебное меню».

## Что видно в меню

- версия приложения и имя пакета;
- версия контента и сколько файлов лежит в кэше;
- статус загрузки контента;
- режим простоя: сколько роликов в кэше, через сколько секунд он включается, громкость роликов;
- статус киоска: «включён», «на паузе» или «выключен»;
- версия в облаке, статус обновления, когда была последняя проверка и когда следующая;
- текст ошибки, если она есть.

## Журнал обновлений

Под строкой «Обновление» показаны последние записи журнала, новые сверху: когда стенд проверял облако и что там нашёл, скачалась ли версия, почему она ждёт, ответ системы на установку. Ошибки выделены красным. Журнал хранится на планшете и переживает перезапуск и установку новой версии. В logcat те же строки идут с тегом `AerocellUpdate`.

Новая версия ставится сама, как только стенд свободен: музыка не играет, меню и окна закрыты и 2 минуты нет касаний. Если уже идут ролики простоя, ждать не нужно. Ночью тоже ставится. На время установки киоск ненадолго снимается, потому что в режиме блокировки HyperOS отменяет установку. Новая версия сама поднимает стенд и запирает экран снова: HyperOS не даёт приложению без «автозапуска» стартовать по сигналу о замене пакета, поэтому стенд поднимается по ответу установщика. Если установка упала, стенд повторит её через 5 минут, всего до трёх попыток.

На Xiaomi (HyperOS) стенду нужны разрешения «Автозапуск» и «Запуск в фоне», иначе после тихого обновления система не даст ему подняться и на экране останутся «Недавние». Скрипт `tools/provision_tablet.ps1` выдаёт их сам. Вручную через adb:

```
adb shell appops set com.aerocell.stand 10008 allow
adb shell appops set com.aerocell.stand 10021 allow
```

Если стенд всё же не поднялся, в журнале будет красная строка «стенд не поднялся сам».

## Что можно сделать

- «Показать режим простоя» — сразу включает экран простоя, чтобы проверить ролики или картинки.
- «Проверить обновления» — спрашивает облако, не дожидаясь перезапуска. Если есть новая версия приложения, появляется кнопка «Обновить»: она закрывает меню, плавно гасит музыку и ставит обновление.
- «Wi-Fi» — список сетей рядом: выберите сеть, введите пароль, «Подключить». Если сети не видно, кнопка «Настройки Wi-Fi» открывает системную панель.
- «Выйти из киоска» — на время снимает блокировку, чтобы можно было открыть настройки планшета.
- «Вернуть киоск» — снова включает блокировку. Она также вернётся сама, когда стенд уйдёт в простой.
- «Закрыть» — просто закрывает меню.
- «Снять режим киоска» — мелкая строка внизу меню, после подтверждения «Вы уверены?». Это уже не пауза: тихие обновления и блокировка выхода пропадут, пока планшет снова не настроят скриптом. Если снять режим не получается, остаётся только сброс до заводских.

## Главное меню, калькулятор и каталог

Стенд стартует с главного меню: «Сравнение» на две трети экрана, справа «Калькулятор» и «Каталог». Из сравнения в меню ведёт круглая стрелка слева вверху, музыка при этом плавно гаснет. После простоя стенд тоже возвращается в меню.

«Калькулятор» и «Каталог» открывают сайт на весь экран: окно вырастает из плитки, сверху шапка со стрелкой назад и крестиком. Окно закрывается крестиком или само, когда стенд уходит в простой; куки и кэш после него стираются. Внутри окна открываются только stp-russia.ru, stplus.ru, их поддомены и домен калькулятора. Звонки, почта, чужие приложения, скачивания и выбор файлов не работают.

Адреса и подписи меняются в манифесте, без новой сборки:

```json
"config": {
  "links": {
    "catalog": {"url": "https://stp-russia.ru/catalog/", "label": "Каталог"},
    "calculator": {"url": "https://stp-russia.ru/calculation/", "label": "Калькулятор"},
    "allowedDomains": []
  }
}
```

Если раздела нет или адрес не http(s), стенд берёт эти же значения по умолчанию. Старый ключ `site` из 1.7.0 тоже работает: он открывается как каталог, если `catalog` не задан. В `allowedDomains` можно добавить ещё домены, если калькулятор переедет.

Подробности первой настройки планшета, скрипта `provision_tablet.bat` и диагностики — в `docs/KIOSK.md`.
