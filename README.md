# AEROCELL — стенд стерео-баланса

Нативное Android-приложение для ландшафтного планшета. Три трека уже внутри APK, интернет не нужен.

## Установка

1. Скачайте `AEROCELL-debug.apk` из этого репозитория.
2. Скопируйте файл на планшет и разрешите установку из этого источника.
3. Откройте **AEROCELL**.

При первом запуске Android может спросить доступ к микрофону. Это нужно только визуализатору, запись не ведётся.

Экран не гаснет, ориентация — ландшафт, как в остальных стендах StP.

## Как пользоваться

- Слева нажмите жанр — трек **сразу стартует с начала**.
- По центру — визуализация. Нажмите на неё, чтобы поставить паузу или продолжить.
- Полоска под волнами — перемотка. Квадрат справа — стоп.
- Нижняя широкая полоса — **стерео баланс**. Тяните влево или вправо: один канал громче, второй тише.

## Сборка

Нужны JDK 17+ (подойдёт JBR из Android Studio) и Android SDK 34.

```bat
gradlew.bat assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
